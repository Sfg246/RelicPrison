# RelicPrison 1.0.0

RelicPrison 1.0.0 is the official stable/final release for Java 25. It is compiled against Paper 1.21.10 and startup-tested with the exact published JAR on Paper 1.21.5 through 26.2.

## Supported Paper range

The automated startup compatibility probe reached `READY` on:

- Paper 1.21.5
- Paper 1.21.6
- Paper 1.21.7
- Paper 1.21.8
- Paper 1.21.9
- Paper 1.21.10
- Paper 1.21.11
- Paper 26.1.1
- Paper 26.1.2
- Paper 26.2

Paper 1.21.4 does not pass the startup probe. Its plugin remapper cannot process the Java 25 class format used by RelicPrison 1.0.0, so 1.21.4 and older versions are not advertised as supported.

The compatibility probe verifies startup, required dependency connection, database/core-service initialization, and the RelicPrison `READY` state. It does not replace feature-by-feature manual regression testing on every listed Paper version.

## Release-polish changes

- Promotes the artifact and filtered `plugin.yml` version to `1.0.0`.
- Adds a configurable READY-only startup presentation with live environment, storage, content counts, integration states, and monotonic startup timing.
- Replaces repository-controlled deprecated Paper/Bukkit API usage with supported Paper 1.21.10 and Adventure APIs.
- Configures Java 25 native access for SQLite tests and documents the corresponding Paper startup option.
- Synchronizes CI, automated reports, checksums, and current documentation.

## Verification boundary

The automated Maven suite, Checkstyle, duplicate-class verification, production-JAR verification, and Paper startup compatibility matrix provide strong automated coverage for the released artifact.

Real Java/Bedrock client behavior, optional integrations, failure injection, restore workflows, and multi-server deployment checks remain manual verification work. No unperformed result is claimed as passed.
