# RelicPrison 1.0.0

RelicPrison 1.0.0 is the official stable/final version for Paper 1.21.10 and Java 25.

## Release-polish changes

- Promotes the artifact and filtered `plugin.yml` version to `1.0.0`.
- Adds a configurable READY-only startup presentation with live environment, storage, content counts, integration states, and monotonic startup timing.
- Replaces repository-controlled deprecated Paper/Bukkit API usage with supported Paper 1.21.10 and Adventure APIs.
- Configures Java 25 native access for SQLite tests and documents the corresponding Paper startup option.
- Synchronizes CI, automated reports, checksums, and current documentation.

## Verification boundary

The automated Maven suite, Checkstyle, duplicate-class verification, and production-JAR verification are recorded in `TEST-REPORT-1.0.0.md`. Historical RC evidence remains unchanged.

Real-server, integration, client, failure, restore, and multi-server checks listed in the staging checklist remain manual verification work. No unperformed result is claimed as passed.
